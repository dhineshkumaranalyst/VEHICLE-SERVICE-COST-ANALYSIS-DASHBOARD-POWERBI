# VEHICLE-SERVICE-COST-ANALYSIS-DASHBOARD-POWERBI

An interactive **Power BI** dashboard analysing vehicle service costs across cities, service types and time.

## Key Metrics
| Metric | Value |
|---|---|
| Total Services | 200 |
| Cities Covered | 8 |
| Total Cost | 2M |
| Labour Cost | 670K |
| Parts Cost | 2M |

## Visuals
- **Cost by Service Type** - Engine Repair, Full Service, Oil Change, Brake Service and more
- **Total Cost over Service Date** - trend of service spending over time
- **Total Cost by City** - Thanjavur, Trichy, Erode, Tiruppur, Madurai, Coimbatore, Chennai, Salem
- **Slicers** - filter by City and Service Type

## Tools Used
- Microsoft Power BI (data modelling, DAX measures, visualisation)
